# NDZDH6_APIcsharp

A C# console application project built with .NET 8.0.

## Getting Started

### Prerequisites
- .NET 8.0 SDK or later

### Build and Run
```bash
# Build the project
dotnet build

# Run the application
dotnet run

# Clean build artifacts
dotnet clean
```

## Project Structure
- `Program.cs` - Main entry point
- `NDZDH6_APIcsharp.csproj` - Project configuration file
